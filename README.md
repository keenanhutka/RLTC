# Rabbit Lake Trading Company

*Northern Goods & Fine Imports*

Static website for Rabbit Lake Trading Company (Kenora area, Northwestern Ontario), hosted on GitHub Pages at https://keenanhutka.github.io/RLTC/.

Plain HTML and CSS with a small script for the mobile menu. No build step: edit the `.html` files directly.

## Placeholders to fill in
- `EMAIL_TO_FILL_IN` (all pages: footer, Contact, mailto links)
- `PHONE_TO_FILL_IN` (footer, Contact)
- Bracketed notes shown on the site, e.g. `[to be confirmed]` lead times and shipping (For Retailers), maker terms and area (Local Makers), and Keenan's story (About)
